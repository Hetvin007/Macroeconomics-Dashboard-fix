# Macro Intelligence Terminal v1.7

## Decision-support layer

v1.7 adds a transparent macro decision-support module on top of the v1.6 relative/global engine.

### New features
- Current macro score and regime for a selected anchor economy.
- Growth, inflation, labor and real-policy-rate interpretations.
- Relative macro watchlist showing the largest divergences from the anchor.
- Scenario stress matrix for Soft Landing, Inflation Shock, Growth Shock, Policy Easing and Global Risk-Off.
- Explicit labeling: decision support only; not investment advice or a price forecast.

### Data discipline
Official observations, derived analytics, and scenario overlays remain separate. No consensus or market values are fabricated.

### Next direction
A later version can add validated portfolio exposures, benchmark-aware factor attribution, and alert routing without turning heuristic signals into unsupported forecasts.
